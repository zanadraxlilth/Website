ZANADRAXLILTH GitHub Pages website files

UPLOAD THESE FILES TO THE ROOT OF YOUR EXISTING GITHUB REPOSITORY:
- index.html
- assets/zx-monogram.webp
- assets/zanadraxlilth-wordmark.webp

Keep the assets folder and both image files together. Do not rename them.
Then open your repository Settings > Pages and select Deploy from a branch, choose your main branch and / (root), then Save.

IMPORTANT:
This package includes the existing custom storefront template with the supplied ZX monogram and ZANADRAXLILTH wordmark. The Shopify/Printify live product integration still needs your Shopify store domain and public Storefront API token configured, plus live product/cart wiring and testing. The current template still contains demo products until that integration is completed.
Do not add a Shopify Admin API token or password to this website.
